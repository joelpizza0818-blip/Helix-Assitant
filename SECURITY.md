# Security Policy

## Reporting a vulnerability

Please do not disclose suspected vulnerabilities in public issues, discussions,
or pull requests.

GitHub private vulnerability reporting is currently disabled for this
repository. Until a private reporting channel is available, contact the
maintainer through private contact information published on their GitHub
profile. If no private contact method is available, open a GitHub issue asking
for a private reporting channel, without including vulnerability details,
reproduction steps, or sensitive information.

Please include affected versions or commits, impact, and concise reproduction
steps only after a private channel has been established. Do not include
credentials or personal data.

## Supported versions

No separate security-support window is published. Check the
[release page](https://github.com/joelpizza0818-blip/Helix-Assitant/releases)
for current artifacts and version information.
