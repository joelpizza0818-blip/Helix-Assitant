# Support

HELIX is maintained through this repository; no response-time or support
service-level agreement is offered.

## Before asking for help

1. Check the [Frequently Asked Questions](FAQ.md) and relevant guides:
   [architecture](docs/ARCHITECTURE.md), [environment](docs/ENVIRONMENT.md),
   and [project flow](docs/PROJECT_FLOW.md).
2. Search [existing GitHub issues](https://github.com/joelpizza0818-blip/Helix-Assitant/issues)
   for the same question or problem.
3. Check that the issue is reproducible with your current HELIX version and
   note the affected component and operating system.

## Open a support issue

Use [GitHub Issues](https://github.com/joelpizza0818-blip/Helix-Assitant/issues)
for questions and bug reports. Include the steps to reproduce, expected and
actual behavior, and the relevant version, platform, and logs with sensitive
information removed.

Never post API keys, passwords, access tokens, private download URLs, personal
data, or unredacted configuration files. For suspected security issues, follow
[SECURITY.md](SECURITY.md) instead of opening a public report.
