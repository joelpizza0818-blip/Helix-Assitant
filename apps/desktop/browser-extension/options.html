HELIX Desktop Companion

Paste the pairing token shown in HELIX Toolbox. HELIX opens a dedicated tab in this browser for its browsing tasks, reusing an open tab from the same site when available. HELIX compares tab URL metadata to find a match, but only the selected HELIX-managed tab is readable or controllable by the agent; other tabs' page content is not shared. Snapshots omit form values, but page content may be sent to your configured AI provider as part of a request. The selected tab uses this browser profile and its cookies.

HELIX uses Chrome's browser-debugging permission to send real mouse and keyboard input to the selected HELIX-managed tab. Chrome may show a permission notice when you update the extension. Tabs opened in DevTools may reject control; HELIX will report that instead of switching to another tab.
